Integrating NetLens with LibreNMS

Connect the NetFlow data collected by NetLens (NfSen) to LibreNMS, so router flow statistics appear inside your LibreNMS device views.

Guide coming soon. This page will be filled with the full step-by-step integration guide — covering the NFS exports, the LibreNMS-side mounts, the RRD links, and the LibreNMS configuration needed to display NetFlow graphs per device.

What to expect

  • NFS exports — sharing nfsen-data and nfsen-stat from the NetLens server to the LibreNMS server
  • LibreNMS mounts — mounting the shares so LibreNMS can read the raw flows and RRD graphs
  • RRD links — linking each LibreNMS device to its NfSen profile so the NetFlow tabs appear
  • nfdump on LibreNMS — installing a matching nfdump version to query the flow data
  • Troubleshooting — common issues like empty NetFlow tabs and mount problems after a reboot

Prerequisites

  • A running NetLens container (installation guide)
  • A LibreNMS installation (on the same or a second server)
  • NFS support on both servers (nfs-kernel-server on the NetLens host, nfs-common on LibreNMS)
The NetLens Web UI (port 8070) runs on the NetLens server and is password-protected. The LibreNMS integration reads the flow data directly from the NFS shares — it does not log in to the NfSen Web UI.
