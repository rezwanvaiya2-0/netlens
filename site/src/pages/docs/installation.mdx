# Installation

<p class="docs-sub">NetLens runs as a Dockerized NfSen stack. The install script builds the image, creates bind-mounted data folders, and starts the service on port 8070.</p>

## Prerequisites

- A Linux VPS or host with Docker Engine and the Docker Compose plugin.
- UDP access to the exporter ports you plan to use.
- Enough disk space for raw flow files and RRD statistics.

<aside class="callout warn"><div class="callout-title">Network requirement</div><p>Allow the selected UDP ports in both your cloud firewall and host firewall. The web interface uses TCP 8070.</p></aside>

## Deploy the stack

```bash
# Clone the repository
git clone https://github.com/rezwanvaiya2-0/netlens.git
cd netlens

# Build and start NetLens
sudo ./install.sh
```

## Open the dashboard

Visit `http://<YOUR_IP>:8070/nfsen.php`.

| Field | Default |
| --- | --- |
| Username | `admin` |
| Password | `change-me-now` |
| Web UI | `http://<YOUR_IP>:8070/nfsen.php` |

<aside class="callout danger"><div class="callout-title">Change the default password</div><p>Replace the default credential immediately:</p></aside>

```bash
docker exec netlens htpasswd -b /var/nfsen/etc/.htpasswd admin YourNewPass123
```

## Verify the service

```bash
docker compose ps
docker logs --tail=50 netlens
ss -lunp | grep -E '2055|2056|8070'
```

The container should be running, UDP listeners should be present, and the web UI should load without an authentication loop.
