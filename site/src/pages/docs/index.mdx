## Choose a path

- **New deployment:** follow [Installation](/docs/installation.html), then add a router source.
- **Existing deployment:** use [Operations](/docs/operations.html) for day-to-day changes.
- **LibreNMS on another host:** read the [LibreNMS integration guide](/docs/librenms-integration.html) in full before changing exports.
