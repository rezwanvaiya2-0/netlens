Built for clear network visibility

NetLens gives teams a simple, reliable way to collect raw NetFlow data and turn it into actionable traffic insights without managing a complex stack by hand.

Capture

Listen on UDP ports 2055/2056 and collect NetFlow v5, v9, and IPFIX from routers, firewalls, and edge devices.

Store

Keep all collected flow data in real folders next to your stack so it remains easy to inspect, back up, and rebuild.

Visualize

Turn raw flows into readable graphs and top-source summaries inside the built-in NfSen web interface.

Retain

Apply expiration and max-size rules directly in the UI so the daemon keeps your data clean without manual cleanup.

How it works

From router export to clean traffic insights in a few minutes.

Router

Exports NetFlow data to your VPS over UDP.

→

Ports

Port forwarding sends the traffic directly into the container.

→

nfcapd

Raw flow files are written automatically for each source.

→

nfsend

RRD graphs and top traffic summaries are generated for you.

→

Dashboard

Review charts, sources, and stats from the web UI.

# Flow pipeline
Router ── NetFlow ──► VPS port 2055/2056 ──► container
      ── nfcapd ──► nfsen-data/live/<router>/
      ── nfsend ──► nfsen-stat/live/<router>.rrd
      ──► UI http://YOUR_IP:8070/nfsen.php

Installation

Deploy NetLens in minutes on any VPS or Linux box with Docker and start collecting flow data right away.

Quick start

# 1. Clone the repo
git clone https://github.com/rezwanvaiya2-0/netlens.git
cd netlens

# 2. Build and start
sudo ./install.sh
First run only

The initial build takes a little longer. After that, docker compose up -d starts the stack quickly and keeps your sources, configuration, and archived data in place.

Open the dashboard

Visit http://<YOUR_IP>:8070/nfsen.php in a browser. The UI is protected, and the default login is:

Usernameadmin
Passwordchange-me-now
Change the password immediately

Update it in one command and keep the service live without restarting:

docker exec netlens htpasswd -b /var/nfsen/etc/.htpasswd admin YourNewPass123

Data folders

Your data stays in four real folders next to docker-compose.yml — no hidden Docker-only volumes.

FolderInside the containerPurpose
nfsen-data//var/nfsen/profiles-dataRaw NetFlow capture files
nfsen-stat//var/nfsen/profiles-statRRD graph files and charts
nfsen-var//var/nfsen/varLogs, cache, and runtime state
nfsen-etc//var/nfsen/etcConfig, sources, and auth files
  • Back up anytime: tar czf nfsen-backup.tar.gz nfsen-data nfsen-stat nfsen-var nfsen-etc
  • Data survives rebuilds and restarts — even a full docker compose down -v is safe if you keep the local folders intact.
  • Only deleting the folders themselves removes data — stop the container first if you need to clean up.

Connect a router

UDP ports 2055 and 2056 are already exposed, and a demo router1 source is ready. To add another device:

# 1. Open the port in docker-compose.yml
#    - "2070:2070/udp"

# 2. Add the source and reconfig
docker exec netlens bash -c "sed -i \"/^);$/i\\    'myrouter' => { 'port' => '2070', 'col' => '#FF0000', 'type' => 'netflow' },\" /var/nfsen/etc/nfsen.conf && /var/nfsen/bin/nfsen reconfig"

# 3. Restart the stack
docker compose up -d

Set data retention

In the Web UI, open Profile Admin → live profile → Edit. Set the retention window and storage cap, then save. The daemon applies your rules automatically in the background.
