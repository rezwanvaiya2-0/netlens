Features

Built for clear network visibility

Collect raw NetFlow data and turn it into actionable traffic insights — without managing a complex stack by hand.

Capture

Listen on UDP ports 2055/2056 and collect NetFlow v5, v9, and IPFIX from routers, firewalls, and edge devices.

Store

Keep flow data in real folders next to your stack — easy to inspect, back up, and rebuild, with no hidden Docker volumes.

Visualize

Turn raw flows into readable RRD graphs and top-source summaries inside the built-in NfSen web interface.

Retain

Apply expire and max-size rules directly in the UI so the daemon keeps your data clean without manual cleanup.

How it works

From router export to clean traffic insights

Router

Exports NetFlow data to your VPS over UDP.

Ports

Published UDP ports carry traffic into the container.

nfcapd

Raw flow files are written automatically per source.

nfsend

RRD graphs and top-traffic summaries are generated.

Dashboard

Review charts, sources, and stats from the web UI.

Flow pipeline

exports NetFlow v5 / v9 / IPFIX over UDP

VPS ports 2055 / 2056

Installation

Deploy in minutes

Any VPS or Linux box with Docker — clone, build, and start collecting flow data right away.

quick start
# 1. Clone the repository
git clone https://github.com/rezwanvaiya2-0/netlens.git
cd netlens

# 2. Build and start NetLens
sudo ./install.sh

First run only

The initial build compiles NfSen + NfDump from source (~7 minutes). After that, docker compose up -d starts the stack in seconds and keeps your sources, config, and data intact.

First login

Open the dashboard

http://<YOUR_IP>:8070/nfsen.php

Username

admin

Password

change-me-now

Change the password immediately

One command, takes effect instantly — no restart needed:

docker exec netlens htpasswd -b /var/nfsen/etc/.htpasswd admin YourNewPass123
